# J'apprends le chinois

Application de flashcards pour apprendre le vocabulaire chinois (caractères simplifiés), installable sur Android depuis Chrome et 100 % hors ligne. Aucune donnée ne quitte le téléphone.

› **Révision** avec répétition espacée (FSRS)
› **Création** de cartes avec pinyin et traduction proposés automatiquement
› **Découverte** du vocabulaire HSK 3.0 par niveau
